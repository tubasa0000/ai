# Chat AI Security Hardened

Quickstart:

1. Copy .env.example to .env and adjust values.
2. Install dependencies:

```
npm install
```

3. Run the server locally:

```
npm run dev
```

4. Run the test suite:

```
npm test
```

Notes:
- For production, set NODE_ENV=production and ensure ADMIN_KEY is set.
- Enable strict mode and audit logging as desired via environment variables.
